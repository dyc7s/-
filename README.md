# 基于世界银行WDI数据的全球宏观经济洞察与可视化分析

> 《商业数据分析》期末大作业项目 · Python 全流程实现（数据获取→清洗→模型→可视化→交互大屏）

## 一、项目简介

本项目以**世界银行 WDI（World Development Indicators）开放数据**为唯一数据源，通过官方公开 API 合规获取 45 个主要经济体 2010–2024 年的 10 项宏观指标（GDP 总量/增长率/人均GDP、人口、通胀、失业、进出口、FDI、互联网普及率）及中国/世界 1960–2024 年时间序列，综合运用 **K-Means 市场分群、波士顿矩阵、帕累托/ABC 分类、同比/环比分析、ARIMA 时间序列预测** 5 种商业分析模型，产出 17 张 Python 可视化图与 1 个 Pyecharts 交互大屏，提炼跨国市场进入与宏观趋势的商业建议。

## 二、数据来源与合规声明

| 项目 | 内容 |

| 数据源名称 | 世界银行 WDI（World Development Indicators，世界发展指标） |

| 获取方式 | 官方开放 API 直接下载 JSON —— 白名单方式：**国际组织开放平台公开数据文件下载**（非爬虫） |

| 授权/License | 世界银行开放数据按 **CC BY 4.0** 开放使用 |
| 主表规模 | 45 国 × 15 年 × 10 指标 = 6750 条（长表）/ 675 行（宽表面板），远超 500 条要求 |
| 时间序列 | 中国 & 世界 3 指标 × 1960–2024 = 390 条 |

详细合规声明见 `docs/数据来源合规声明.md`。

## 六、商业分析模型说明

| 模型 | 方法 | 参数/阈值依据 | 核心结论 |
|---|---|---|---|
| M1 K-Means | 5 维标准化特征聚类 | K 由轮廓系数最大确定（K=4） | 45 国分为 4 个发展梯队 |
| M2 波士顿矩阵 | GDP 份额(对数) × 近5年CAGR | 中位数切分（样本量45，稳健） | 明星14/金牛9/问题9/瘦狗13 |
| M3 帕累托/ABC | 2024 GDP 降序累计 | 70%/90% 教科书口径 | A 类 9 国贡献 71.28% |
| M4 同比/环比 | 中国 GDP 年度同比 | 自然年度口径 | 中国近10年均增速 5.97% vs 世界 3.49% |
| M5 ARIMA 预测 | AIC 网格定阶 + 95%CI | 年度无季节性→ARIMA(p,d,q) | 回测 MAPE=3.72%，2029 预测≈15500 美元 |
