## 2. 白名单方式说明

根据作业要求 2.1 节，数据获取须通过白名单方式（严禁爬虫）。本项目采用的获取方式属于白名单第三类：

> **政府/国际组织开放平台的公开数据文件下载。**

世界银行（World Bank Group）是国际组织，其 WDI 数据通过官方 REST API 以 JSON 格式公开提供，任何人均可自由访问与下载，无需注册、无需登录、不涉及任何网页解析或模拟登录。本项目使用 Python 标准库 `urllib` 直接调用该官方 API 端点获取 JSON 数据，**未使用 Scrapy、Selenium、requests+网页解析或任何爬虫技术**。

## 4. 数据字段说明

### 主表（宽表面板 wdi_wide_clean.csv）

| 字段 | 类型 | 说明 |
|---|---|---|
| 国家代码 | str | ISO 3 字母代码（如 CHN、USA） |
| 国家 | str | 国家名称（英文，世界银行原始返回） |
| 年份 | int | 数据年份（2010–2024） |
| GDP总量(美元) | float | 当前美元计 GDP |
| GDP增长率(%) | float | 年度 GDP 增长率 |
| 人均GDP(美元) | float | 当前美元计人均 GDP |
| 总人口 | float | 总人口数 |
| CPI通胀率(%) | float | 消费者价格指数通胀率 |
| 失业率(%) | float | 失业率 |
| 出口占GDP(%) | float | 货物与服务出口占 GDP 比重 |
| 进口占GDP(%) | float | 货物与服务进口占 GDP 比重 |
| 外商直接投资占GDP(%) | float | FDI 净流入占 GDP 比重 |
| 互联网普及率(%) | float | 互联网用户占比 |
| GDP总量(万亿美元) | float | 派生字段 |
| GDP(对数) | float | 派生字段，取自然对数 |
| GDP增长率(%)_异常 | bool | IQR 异常标记 |
| CPI通胀率(%)_异常 | bool | IQR 异常标记 |

### 时间序列表（wdi_timeseries_clean.csv）

| 字段 | 类型 | 说明 |
|---|---|---|
| 对象 | str | "中国" 或 "世界" |
| 年份 | int | 1960–2024 |
| 指标 | str | GDP总量(万亿美元)/GDP增长率(%)/人均GDP(美元) |
| 数值 | float | 指标值 |
